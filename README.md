💈 Valhalla Barber Club - Landing Page

Uma landing page moderna, elegante e de alto desempenho desenvolvida para a Valhalla Barber Club. O projeto foi estruturado com foco em experiência do usuário (UX), design responsivo e conversão, incluindo agendamento direto via WhatsApp e catálogo interativo de serviços.

🔗 Acesse o site ao vivo: barbearia-portfolio.leoooosg.workers.dev

🚀 Tecnologias Utilizadas

HTML5: Estruturação semântica do projeto.

CSS3 / Tailwind CSS: Estilização moderna, responsividade e layout elegante.

JavaScript (ES6+): Interatividade, animações e lógica de menu/agendamento.

Cloudflare Pages / Workers: Hospedagem de alta performance e rápida entrega de ativos.

✨ Funcionalidades

[x] Design Responsivo: Adaptado perfeitamente para dispositivos móveis, tablets e desktops.

[x] Seção Hero: Chamada para ação (CTA) destacada para agendamentos rápidos.

[x] Catálogo de Serviços: Apresentação clara de cortes, tratamentos de barba e combos.

[x] Integração com WhatsApp: Botões de agendamento direcionam automaticamente para a conversa no WhatsApp.

[x] Avaliações & Depoimentos: Prova social integrada para gerar autoridade e confiança.

[x] Localização e Contato: Informações detalhadas de endereço e horário de funcionamento.

🛠️ Como rodar o projeto localmente

Clone este repositório:

git clone https://github.com/LeonardoSG07/barbearia_portfolio.git


Entre na pasta do projeto:

cd barbearia_portfolio


Abra o arquivo index.html diretamente no seu navegador ou utilize a extensão Live Server no VS Code.
